# Purpose

This document marks the official documentation baseline for ORION v1.1.0 — Executive Experience.

The [ORION Product Bible](./00_BLUEPRINT/ORION_Product_Bible.md) is the primary reference for all product decisions. Where conflicts exist between documents, the Product Bible takes precedence.

Governance structure: [ORION Governance Framework](./09_Standards/ORION_Governance_Framework.md).

All architectural, governance, and standards documentation required before Business Capability Development is complete and approved.

Future documentation changes for routine feature work follow Engineering Specifications and Release Records. Updates to this baseline occur at major version milestones (v1.2, v2.0, etc.).
