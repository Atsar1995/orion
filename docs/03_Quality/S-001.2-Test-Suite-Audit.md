## Detailed Failure Analysis

### Group A — Finance Event Pipeline (7 failures) — **Regression F05**

**Root cause:** In `FinancialEventPipelineService.processIntake()`, the intake record is persisted at line 60–71 **before** `rules.validateIntake()` at line 75. `PipelineRulesEngine.validateDuplicate()` then finds the just-created intake via `intakeRepository.findByIdempotencyKey()` and returns `DUPLICATE_INTAKE` on **every** first-time call.

**Evidence:**
```
Expected: result.success = true  →  Received: false
Expected: AUTHORIZED_SOURCE      →  Received: DUPLICATE_INTAKE
Expected: /PERIOD/               →  Received: DUPLICATE_INTAKE
```

**Not:** flaky, timing, or environment — deterministic logic ordering bug.

**Fix:** Validate before persist, or pass `excludeIntakeId` to duplicate check.

**Estimated effort:** 2–3 hours including test verification.

---

### Group B — CRM Certification Docs (4 failures) — **Configuration Problem**

**Root cause:** Certification tests require two files per mission:
- `P-008.x-*-Platform.md` — **exists**
- `P-008.x-*-Certification.md` — **missing** (0 Certification files in `docs/03_Architecture/`)

**Evidence:** `existsSync(...Certification.md)` returns `false`.

**Not:** regression in CRM code — functional tests in same files **pass**.

**Fix:** Author 4 certification markdown files (~1 page each).

**Estimated effort:** 2–4 hours.

### Group C — Finance Bootstrap Mission ID (2 failures) — **Incorrect Test**

**Root cause:** `FinanceFacade.getWorkspaceBootstrap()` returns `mission: FINANCE_MISSION_EXECUTIVE_INTELLIGENCE` (`P-009.7`) for all contexts. Tests for P-009.5 and P-009.6 assert `bootstrap.mission` equals their mission ID.

**Evidence:**
```
Expected: "P-009.6"  →  Received: "P-009.7"
Expected: "P-009.5"  →  Received: "P-009.7"
```

**Not:** regression — facade intentionally points to latest mission. Capability flags (`eventPipelineImplemented`, `fiscalPeriodImplemented`) are `true`.

**Fix:** Update tests to assert `FINANCE_FOUNDATION_CAPABILITIES` or domain status, not bootstrap mission.

**Estimated effort:** 30 minutes.
