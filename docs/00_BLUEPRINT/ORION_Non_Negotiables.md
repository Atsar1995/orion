# Purpose

This document defines the principles that shall never be compromised during the design, development, operation, or evolution of ORION.

These are not recommendations.

They are non-negotiable commitments.

**Master reference:** [ORION Product Bible](./ORION_Product_Bible.md) · [ORION Project Charter](./ORION_Project_Charter.md)

---

# Non-Negotiable 1 — Executive Trust

Every number displayed by ORION must be accurate.

If confidence is uncertain, ORION shall clearly communicate that uncertainty.

Trust is never sacrificed for convenience.

**Reference:** [Intelligence Constitution](../05_AI/ORION_Intelligence_Constitution.md) Principle 10 · [Product Constitution](../01_Product/ORION_Product_Constitution.md) Principle 10

---

# Non-Negotiable 2 — Executive Time

Every screen must save executive time.

Every feature must reduce effort.

Every interaction must have a purpose.

**Reference:** [FA-003 Project Pulse](../01_Product/FA-003-Project-Pulse.md) · [Product Constitution](../01_Product/ORION_Product_Constitution.md) Principle 7

---

# Non-Negotiable 3 — Clarity

If an executive cannot understand a screen within sixty seconds, the design should be reconsidered.

**Reference:** [Product Bible](./ORION_Product_Bible.md) · [Project Charter](./ORION_Project_Charter.md)

---

# Non-Negotiable 4 — Explainability

Recommendations must explain:

- Why
- Evidence
- Expected outcome

No unexplained intelligence.

**Reference:** [Intelligence Constitution](../05_AI/ORION_Intelligence_Constitution.md) Principle 4 · [Decision Framework](../05_AI/ORION_Decision_Framework.md)

---

# Non-Negotiable 5 — Architecture

No implementation may weaken the approved architecture.

Temporary shortcuts must be documented.

**Reference:** [ORION Constitution](../09_Standards/ORION_Constitution.md) · [Technical Debt Register](../09_Standards/Technical_Debt_Register.md) · [Engineering Manifesto](../09_Standards/ORION_Engineering_Manifesto.md) Principle 1

---

# Non-Negotiable 6 — Security

Executive information is confidential.

Security is designed into the platform from the beginning.

**Reference:** [Engineering Standards](../09_Standards/Engineering_Standards.md) · [PA-001](../03_Architecture/ORION_Platform_Architecture.md)

---

# Non-Negotiable 7 — Maintainability

Future engineers should understand today's work.

Readable systems are valuable systems.

**Reference:** [Engineering Manifesto](../09_Standards/ORION_Engineering_Manifesto.md) Principles 3–4 · [OS-001 Naming Standards](../09_Standards/OS-001-Naming-Standards.md)

---

# Non-Negotiable 8 — Consistency

A concept should behave the same way throughout ORION.

Users should never have to relearn similar functionality.

**Reference:** [Product Constitution](../01_Product/ORION_Product_Constitution.md) Principle 5 (One Truth) · [Design System](../04_Design/ORION_Design_System.md)

---

# Non-Negotiable 9 — Quality

Working software is not enough.

Reliable software is required.

**Reference:** [Engineering Standards — Verification Hierarchy](../09_Standards/Engineering_Standards.md#verification-hierarchy) · [OS-002 Work Item Lifecycle](../09_Standards/OS-002-Work-Item-Lifecycle.md)

---

# Non-Negotiable 10 — Executive Value

Before implementing any feature ask:

**Does this create measurable value for executives?**

If not, challenge the feature.

**Reference:** [Product Bible — Product Test](./ORION_Product_Bible.md#product-test) · [FA-001 Project Sunrise](../01_Product/FA-001-Project-Sunrise.md)

---

# Decision Filter

Before approving any work ask:

- Does it improve clarity?
- Does it improve trust?
- Does it save time?
- Does it improve decisions?
- Does it strengthen ORION?

If **No** to all — do not proceed without Founder or Chief Architect review.
