# Daily Log Format

Create one file per day during the exercise:

```
daily-log/day-01.md
daily-log/day-02.md
...
daily-log/day-07.md
```

Each entry should record questions exactly as they appear:

```markdown
## 2026-07-24 — 09:15

Which customers have not paid their invoices?

## 2026-07-24 — 11:40

How many rooms are vacant this weekend?
```
