# Daily Log Format

Create one file per day during the exercise:

```
daily-log/day-01.md
daily-log/day-02.md
...
daily-log/day-07.md
```

Each decision entry should capture all seven fields:

```markdown
## Decision — 2026-07-24 — 14:30

**Category:** Hospitality

### 1. What happened?

A guest requested an early check-in.

### 2. What question did you ask yourself?

Can we accommodate the request without affecting today's arrivals?

### 3. What information did you need?

Room availability. Housekeeping status. Expected arrivals.

### 4. Where did the information come from?

Phone call with front desk. Memory of today's schedule.

### 5. What decision did you make?

Approve early check-in.

### 6. Why?

Room was already cleaned. No conflicting reservations. VIP customer.

### 7. What happened afterwards?

Guest appreciated the flexibility. Excellent review received.

---

## Daily Review — Top Three Decisions

1.
2.
3.
```
