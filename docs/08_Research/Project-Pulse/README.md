# Daily Log Format

Create one file per day during the exercise:

```
daily-log/day-01.md
daily-log/day-02.md
...
daily-log/day-07.md
```

Each activity entry should capture:

```markdown
## 08:00 — Hospitality

**Activity:** Review overnight bookings

**Reason:** Prepare for morning arrivals

**Duration:** 15 minutes

**Priority:** High

**Energy:** High

**Focus:** Routine Work

**Interruptions:** 1

**Result:** Completed

---

## Daily Review

- What created the most value today?
- What wasted the most time today?
- What should never require my attention again?
- What could ORION automate?
- What could ORION summarize?
```

# End of Week

Complete `week-summary.md` with estimated hours per category (Hospitality, Commerce, Finance, etc.).

# After the Exercise

The CTO will analyse collected activity data and produce:

- Executive Attention Analysis

- Dashboard priority recommendations
- Executive Brief and workflow improvements
