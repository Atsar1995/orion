## Release Objectives

v1.0.1 consolidates the **Enterprise HCM v1.0** domain release and the **P-013 Enterprise Governance Framework** into a single platform release candidate suitable for stabilization toward GA.

| Objective | Scope |
|-----------|-------|
| Enterprise HCM | P-012 / S-002.3–S-002.8 — facade, APIs, events, workflow, documentation |
| Governance framework | P-013.1–P-013.9+ — Architecture Handbook, ES-090–ES-097 |
| Release discipline | Unified release docs in `docs/06_Releases/` (P-013.11) |
| Certification path | CONDITIONAL GO → GO after P0 debt remediation |
