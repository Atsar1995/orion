## Executive Summary

ORION **v1.0.1-rc1** is the first **enterprise release candidate** combining:

1. **Enterprise HCM v1.0** — complete workforce domain (P-012 / S-002.3–S-002.8)
2. **Enterprise Governance Framework** — Architecture Handbook and ES-090–ES-097 standards (P-013)

**Certification: CONDITIONAL GO** — architecture and domain services certified for RC deployment. **GA blocked** until persistent storage (TD-HCM-001) and HCM permission hooks (TD-HCM-005) are remediated.

This RC supersedes tag `v1.0.0-rc1` (same baseline commit) with updated release line numbering and consolidated release documentation.

## Major Deliverables

### Enterprise HCM (P-012)

| Module | Capabilities |
|--------|-------------|
| Organization | Org units, positions, hierarchy, reporting |
| Employee | Master data, identity, activation, suspension |
| Employment | Transfer, promote, terminate, rehire |
| Recruitment | Candidates, applications, offers, hire |
| Onboarding | Process, documents, tasks, provisioning |
| Time | Attendance, leave, roster, calendars, overtime |
| Payroll | Periods, calculation, adjustments (facade) |
| Talent | Goals, reviews, learning, certifications (facade) |

**Integration:**

- **`hcmFacade`** — single public entry (`@/lib/hcm`)
- **48 REST routes** — foundation + time APIs with standard envelopes
- **67+ IIL events** — workflow triggers, cross-domain integration
- **13 workflow templates** — leave, attendance, recruitment, onboarding, employment
