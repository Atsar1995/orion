## 6. Production Architecture Baseline

### 6.1 Approved Production Architecture (Target v1.0.x GA)

```
┌─────────────────────────────────────────────────────────────┐
│                    Executive Shell (ADR-001)                 │
│              Session Auth (ADR-008) · UI RBAC                │
└──────────────────────────┬──────────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────────┐
│  Domain APIs — fail-closed · PermissionService (ADR-009)       │
│  HCM Facade → Service → Repository → PostgreSQL (ADR-007)    │
└──────────────────────────┬──────────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────────┐
│  Platform: IIL (in-process GA) · Workflow · Identity         │
│  Config/Secrets (ADR-010) · Health/Observability (ADR-011)   │
└──────────────────────────┬──────────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────────┐
│  PostgreSQL (production) · SQLite (dev/CI only)                │
│  Deploy: CI → Staging → Prod (ADR-012)                         │
└─────────────────────────────────────────────────────────────┘
```
