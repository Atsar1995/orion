## Executive Summary

This document defines **every reusable enterprise platform capability** in ORION. It is the consumption contract between Platform Engineering and all domain teams.

| Assessment | Verdict |
|------------|---------|
| **P-014.2 capability matrix mission** | **GO** |
| **Capability catalog completeness** | **GO** |
| **Alignment with v2.0 baseline** | **GO** |
| **Platform production-ready for all domains** | **CONDITIONAL GO** — GL persist · CRM facade unification · analytics ingest |
| **Domain teams may bypass platform services** | **NO-GO** — constitutional violation |

**Current state:** **12 capabilities certified or production-ready** · **18 implemented** · **11 prototype/planned** · **8 future/not started**.

**Strategic rule:** Domains implement **business logic only**. Platform owns persistence, identity, security, events, workflow, observability, and AI governance.

## 1. Purpose & Scope

### 1.1 Purpose

Provide a single authoritative catalog specifying, for each capability:

- Purpose · Owner · Platform component · Public interfaces
- Consuming domains · Dependencies · Maturity · Certification · Roadmap

### 1.2 Maturity Scale

| Level | Definition |
|-------|------------|
| **Not Started** | No implementation; architecture may exist |
| **Planned** | ADR or ES approved; mission scheduled |
| **Prototype** | Code exists; not domain-integrated or not certified |
| **Implemented** | Production code integrated in ≥1 domain path |
| **Certified** | Gate/GA certification tests pass |
| **Production Ready** | Certified + staging/live ops evidence |

### 1.3 Classification Scale

| Class | Definition | Examples |
|-------|------------|----------|
| **Foundation** | Required by all domains; no bypass | PlatformStore · Identity · RBAC · IIL |
| **Core Platform** | Shared runtime services | Workflow · Configuration · Feature Flags |

| **AI Service** | Governed intelligence layer | AI Platform · Prompt Library · Agents |
| **Developer Service** | Engineering and release tooling | Testing · Certification · Developer SDK |
| **Operational Service** | Run · monitor · recover | Observability · Health · Secrets |
| **Future** | Planned v2.2+; no consumption yet | GraphQL · Licensing · Localization |

| **D6** | Certification MUST use Certification Framework — no bespoke gate processes |
