## Maintenance

These documents describe ORION's architecture at a high level.

Update them only when there is a significant architectural change, such as:

- Introduction of a new platform layer
- Addition of a major shared service
- Changes to workspace relationships
- Significant revisions to the Executive Experience
- Adoption of a new architectural pattern

Routine feature development should not require changes to these documents.
