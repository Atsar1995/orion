# P-007.2 — Reservation Management Engine API

**Base path:** `/api/hospitality/reservations`  

---

## Reservations

### `GET /api/hospitality/reservations`
List all reservations (search view).

### `POST /api/hospitality/reservations`
Create reservation via engine.

**Body:** `CreateReservationInput`

**Errors:** `409 RESERVATION_CONFLICT`

### `GET /api/hospitality/reservations/[id]`
Reservation detail with conflict detection.

### `PATCH /api/hospitality/reservations/[id]`
Modify reservation or execute action.

**Modify body:** `ModifyReservationInput`

**Action body:** `{ "action": "check_in" | "check_out" | "cancel" | "reinstate" | "extend" | "shorten" | "upgrade" | "downgrade" | "transfer" | "archive", "payload"?: {} }`

---

## Search

### `GET /api/hospitality/reservations/search`
**Query:** `query`, `reservationNumber`, `guestId`, `status`, `source`, `propertyId`, `arrivalFrom`, `arrivalTo`, `agentName`, `companyName`

---

## Calendar

### `GET /api/hospitality/reservations/calendar`
**Query:** `mode` (daily|weekly|monthly|timeline), `date`, `propertyId`

---

## Availability

### `GET /api/hospitality/reservations/availability`
**Query:** `propertyId`, `arrival`, `departure`, `accommodationTypeId`, `adults`, `children`, `infants`

Returns available inventory units for the date range.

---

## Error Codes

| Code | Meaning |
|------|---------|
| `RESERVATION_NOT_FOUND` | Invalid ID or org scope |
| `RESERVATION_CONFLICT` | Allocation or overbooking conflict |
| `INVALID_TRANSITION` | Lifecycle action not permitted |
| `INVALID_GUEST_COUNT` | Exceeds accommodation capacity |
| `INVALID_STAY_DATES` | Arrival ≥ departure |
| `ALLOCATION_CONFLICT` | Inventory unit already booked |
