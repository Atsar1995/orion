# P-007.5 — Housekeeping & Maintenance Operations Platform Architecture

**Mission:** P-007.5 — Housekeeping & Maintenance Operations Platform  
**Epic:** P-007 Hospitality Workspace v1.0  
**Status:** Production-ready (in-memory persistence)  

---

## Purpose

The Housekeeping & Maintenance Operations Platform coordinates room readiness, cleaning workflows, preventive and corrective maintenance, inspections, and asset health across hospitality properties. Every status change is event-driven — checkout creates cleaning tasks, completion triggers inspection, inspection pass syncs inventory to clean, and maintenance blocks/unblocks rooms automatically.

|---------|----------------|
| `HousekeepingBoardService` | Room status board, cleaning queue, readiness summary |
| `CleaningWorkflowService` | Task lifecycle — create, assign, start, complete, inspect |
| `MaintenanceWorkOrderService` | Work orders, asset register, preventive schedules |
| `RoomStatusService` | Inventory status sync via `StatusService` |
| `HousekeepingRulesEngine` | Task and work order validation |

Public facade: `hospitalityHousekeepingService`

---

## Operational Workflow

```
Check-out (P-007.4) → Auto cleaning task (checkout)
  → Assign → Start → Complete → Inventory: inspecting
  → Inspect pass → Inventory: clean (vacant clean)
  → Inspect fail → Re-clean task, Inventory: dirty

Maintenance request (critical/high) → Block room
  → Resolve → Unblock → Inventory: dirty (needs cleaning)
```

---

## Extended Room Status

Maps inventory status + active task + maintenance hold to operational status:

- Vacant Clean / Vacant Dirty
- Occupied Clean / Occupied Dirty
- Inspected
- Out of Order / Out of Service
- Under Maintenance / Blocked

## Platform Integration

| Platform | Integration |
|----------|-------------|
| Front Office (P-007.4) | Checkout auto-creates cleaning task |
| Inventory (P-007.1) | Room status sync on clean/inspect/maintenance |
| Executive Brief | Ready rooms, awaiting cleaning, critical maintenance, asset health |
| Decision Intelligence | Staff allocation, maintenance priorities, cleaning efficiency |
| Executive Memory | Cleaning history, maintenance history, inspection outcomes |
| IIL | `HousekeepingTaskCreated`, `HousekeepingCompleted`, `RoomInspected`, `MaintenanceRequested`, `MaintenanceResolved`, `InspectionFailed` |

---

## CTO Recommendation

Housekeeping and maintenance operate as **event-driven services**. Every status change, inspection result, work order, and maintenance event automatically updates Availability, Executive Brief, Executive Memory, and Decision Intelligence without manual intervention.
