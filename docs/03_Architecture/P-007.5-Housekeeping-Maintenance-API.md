# P-007.5 — Housekeeping & Maintenance Operations API

**Base path:** `/api/hospitality/housekeeping`  

---

## Dashboard

### `GET /api/hospitality/housekeeping`
**Query:** `propertyId`

Returns housekeeping dashboard (board, queue, summary), maintenance dashboard, assets, schedules, linen, and lost & found.

---

## Cleaning Tasks

### `POST /api/hospitality/housekeeping/tasks`
**Body:** `CreateHousekeepingTaskInput` — `propertyId`, `inventoryItemId`, optional `stayId`, `cleaningType`, `priority`, `notes`

### `POST /api/hospitality/housekeeping/tasks/[id]/assign`
**Body:** `{ "assignedTo": string }`

**Errors:** `TASK_NOT_FOUND`, `INVALID_TASK_STATUS`

### `POST /api/hospitality/housekeeping/tasks/[id]/complete`

Marks task completed and sets inventory status to `inspecting`.

**Errors:** `TASK_NOT_FOUND`, `INVALID_TASK_STATUS`

### `POST /api/hospitality/housekeeping/tasks/[id]/inspect`
**Body:** `{ "passed": boolean }` (default `true`)

On pass: inventory → `clean`. On fail: inventory → `dirty`, publishes `InspectionFailed`.

**Errors:** `TASK_NOT_FOUND`, `INVALID_TASK_STATUS`

---

## Maintenance

### `GET /api/hospitality/housekeeping/maintenance`
**Query:** `propertyId`

Returns maintenance dashboard with work orders, backlog, critical count, preventive due.

### `POST /api/hospitality/housekeeping/maintenance`
**Body:** `CreateMaintenanceInput` — `propertyId`, optional `inventoryItemId`, `assetId`, `title`, `description`, `type`, `priority`, `assignedTo`, `vendorName`, `scheduledAt`

Critical/high priority with room scope blocks inventory for maintenance.

### `POST /api/hospitality/housekeeping/maintenance/[id]`
Resolves work order, unblocks room, sets inventory to dirty for cleaning.

**Errors:** `WORK_ORDER_NOT_FOUND`, `INVALID_WORK_ORDER_STATUS`

---

## Error Codes

| Code | Meaning |
|------|---------|
| `TASK_NOT_FOUND` | Invalid task ID or org scope |
| `INVALID_TASK_STATUS` | Action not permitted for current task status |
| `WORK_ORDER_NOT_FOUND` | Invalid work order ID or org scope |
| `INVALID_WORK_ORDER_STATUS` | Resolve not permitted for current status |

---

## Event Types (IIL)

| Event | Trigger |
|-------|---------|
| `HousekeepingTaskCreated` | Task created (incl. checkout auto-create) |
| `HousekeepingCompleted` | Cleaning marked complete |
| `RoomInspected` | Supervisor inspection recorded |
| `InspectionFailed` | Inspection failed — re-clean required |
| `MaintenanceRequested` | Work order created |
| `MaintenanceResolved` | Work order resolved |
