# P-007.1 — Property & Inventory Management API

**Base path:** `/api/hospitality`  
**Authentication:** Session via `getDecisionServiceContext()`  

---

## Properties

### `GET /api/hospitality/properties`
List properties and portfolio for the organization.

### `POST /api/hospitality/properties`
Create a property.

**Body:** `CreatePropertyInput`

**Errors:** `409 DUPLICATE_PROPERTY`

### `GET /api/hospitality/properties/[id]`
Property detail with zones, location, accommodation types, media.

### `PATCH /api/hospitality/properties/[id]`
Update property fields.

### `DELETE /api/hospitality/properties/[id]`
Delete property.

---

## Inventory

### `GET /api/hospitality/inventory`
List inventory items. Query: `propertyId`

### `POST /api/hospitality/inventory`
Create inventory item.

**Errors:** `409 DUPLICATE_ROOM_NUMBER`, `422 INVALID_CAPACITY`

### `GET /api/hospitality/inventory/search`
Search inventory with filters.

**Query:** `propertyId`, `kind`, `status`, `zoneId`, `buildingId`, `query`, `accessibleOnly`, `availableOnly`

### `GET /api/hospitality/inventory/availability`
Daily availability snapshot.

**Query:** `propertyId` (required), `date`

### `POST /api/hospitality/inventory/bulk`
Bulk archive, status update, or import.

**Body:** `BulkInventoryOperation`

---

## Amenities

### `GET /api/hospitality/amenities`
Organization amenity catalog.

---

## Analytics

### `GET /api/hospitality/analytics/properties`
Portfolio inventory analytics — health score, utilization, recommendations.

---

## Error Envelope

```json
{ "success": false, "error": "DUPLICATE_ROOM_NUMBER" }
```

| Code | Meaning |
|------|---------|
| `DUPLICATE_PROPERTY` | Slug already exists |
| `DUPLICATE_ROOM_NUMBER` | Label already exists on property |
| `INVALID_CAPACITY` | Capacity exceeds accommodation type max |
| `PROPERTY_NOT_FOUND` | Property not in organization scope |
| `INVENTORY_NOT_FOUND` | Inventory item not found |
