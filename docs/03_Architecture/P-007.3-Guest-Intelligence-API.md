# P-007.3 — Guest Intelligence API

**Base path:** `/api/hospitality/guests`  

---

## Guests

### `GET /api/hospitality/guests`
List all guests (search view).

### `POST /api/hospitality/guests`
Create guest profile.

**Body:** `CreateGuestInput`

**Errors:** `INVALID_GUEST_NAME`, `CONTACT_REQUIRED`

### `GET /api/hospitality/guests/[id]`
Guest detail with timeline, analytics, duplicate candidates.

### `PATCH /api/hospitality/guests/[id]`
Modify guest profile.

**Body:** `ModifyGuestInput`

---

## Search

### `GET /api/hospitality/guests/search`
**Query:** `query`, `email`, `phone`, `passport`, `loyaltyNumber`, `company`, `reservationNumber`, `loyaltyTier`, `isVip`, `tag`

---

## Timeline

### `GET /api/hospitality/guests/[id]/timeline`
Communication and history timeline for guest.

---

## Preferences

### `GET /api/hospitality/guests/[id]/preferences`
List guest preferences.

### `PATCH /api/hospitality/guests/[id]/preferences`
**Body:** `{ "preferences": GuestPreference[] }`

---

## Relationships

### `GET /api/hospitality/guests/[id]/relationships`
List guest relationships.

### `PATCH /api/hospitality/guests/[id]/relationships`
**Body:** `{ "relationships": GuestRelationship[] }`

---

## Consent

### `GET /api/hospitality/guests/[id]/consent`
List consent records.

### `PATCH /api/hospitality/guests/[id]/consent`
**Body:** `{ "consents": GuestConsent[] }`

---

## Duplicate Detection & Merge

### `GET /api/hospitality/guests/duplicates`
List potential duplicate guest pairs with match scores.

### `POST /api/hospitality/guests/merge`
**Body:** `{ "primaryGuestId": string, "duplicateGuestId": string }`

Merges duplicate into primary profile.

---

## Error Codes

| Code | Meaning |
|------|---------|
| `GUEST_NOT_FOUND` | Invalid ID or org scope |
| `DUPLICATE_NOT_FOUND` | Merge target not found |
| `INVALID_MERGE` | Cannot merge guest with itself |
| `INVALID_GUEST_NAME` | Name required |
| `CONTACT_REQUIRED` | Email or phone required |
