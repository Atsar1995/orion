# P-007.1 — Property & Inventory Management Architecture

**Mission:** P-007.1 — Property & Inventory Management  
**Epic:** P-007 Hospitality Workspace v1.0  
**Status:** Production-ready (in-memory persistence)  
**Applicable Canon:** C-001, C-002, C-003, C-004, C-005, C-006, C-007, C-009  

---

## Purpose

Property & Inventory Management is the operational foundation of the Hospitality Workspace. It provides a canonical, extensible, multi-property accommodation model consumed by reservations, pricing, housekeeping, maintenance, and revenue capabilities.

No workspace module shall define its own inventory structures.

---

## Canonical Inventory Model

```
Organization
  └── Portfolio
        └── Property
              ├── Location (GPS)
              ├── Zone
              ├── Building → Wing → Floor
              ├── AccommodationType
              │     ├── Amenity references
              │     ├── Bed configuration
              │     ├── Views
              │     └── Accessibility profile
              └── InventoryItem (room | suite | villa | cottage | tent | houseboat)
                    ├── Status / Maintenance status
                    ├── Operational status
                    ├── Media assets
                    └── Availability snapshot
```

## Services

| Service | Responsibility |
|---------|----------------|
| `PropertyService` | Portfolio, property CRUD, property detail |
| `InventoryService` | Inventory CRUD, explorer, bulk operations |
| `AccommodationService` | Accommodation type catalog per property |
| `AmenityService` | Org-scoped amenity catalog |
| `MediaService` | Photos, floor plans, documents |
| `LocationService` | GPS / address for properties |
| `StatusService` | Room and maintenance status transitions |
| `InventorySearchService` | Filtered search and availability queries |
| `PropertyAnalyticsService` | Portfolio inventory health and utilization |

Facade: `hospitalityInventoryService` (`HospitalityInventoryFacade`)

## Platform Integration

| Platform | Integration |
|----------|-------------|
| Identity / Organization | `ServiceContext` scopes all data by `organizationId` |
| Executive Brief | `totalProperties`, `inventoryHealthScore`, `unavailableInventory`, `totalCapacity` |
| Decision Intelligence | Inventory optimization, renovation, capacity recommendations |
| IIL | `CustomEvent` with `hospitalityEvent: PropertyUpdated \| InventoryUpdated \| InventoryStatusChanged` |
| Audit | Property/inventory mutations publish IIL events with actor attribution |

---

## Reference Implementation Rule

Future hospitality capabilities (reservations, pricing, housekeeping) **must consume** `InventoryItem`, `AccommodationType`, and `Property` from this module — not define parallel structures.
