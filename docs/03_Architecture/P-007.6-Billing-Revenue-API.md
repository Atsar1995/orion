# P-007.6 — Billing, Folio & Revenue Operations API

**Base path:** `/api/hospitality/billing`  

---

## Dashboard

### `GET /api/hospitality/billing`
**Query:** `propertyId`

Returns billing dashboard (summary, folios, recent payments, revenue by category) and revenue dashboard.

---

## Folios

### `GET /api/hospitality/billing/folios`
**Query:** `propertyId`

List folios with balance summary.

### `POST /api/hospitality/billing/folios`
**Body:** `CreateFolioInput` — `propertyId`, `reservationId`, `guestId`, optional `stayId`, `folioType`, `masterFolioId`, `companyAccountId`

### `GET /api/hospitality/billing/folios/[id]`
Folio detail with charges, payments, deposits, adjustments, invoices, and balance summary.

### `POST /api/hospitality/billing/folios/[id]`
Settle folio (requires zero balance).

**Errors:** `FOLIO_NOT_FOUND`, `OUTSTANDING_BALANCE`

---

## Charges

### `POST /api/hospitality/billing/charges`
**Body:** `PostChargeInput` — `folioId`, `description`, `category`, `amount`, optional `taxCode`, `serviceChargeRate`, `reference`

**Errors:** `FOLIO_NOT_FOUND`, `INVALID_FOLIO_STATUS`

---

## Payments

### `POST /api/hospitality/billing/payments`
**Body:** `ProcessPaymentInput` — `folioId`, `amount`, `method`, optional `reference`

Auto-settles folio when balance reaches zero.

**Errors:** `FOLIO_NOT_FOUND`, `INVALID_FOLIO_STATUS`

---

## Invoices

### `GET /api/hospitality/billing/invoices`
**Query:** `propertyId`

### `POST /api/hospitality/billing/invoices`
**Body:** `GenerateInvoiceInput` — `folioId`, `type` (proforma | tax_invoice | credit_note | debit_note)

---

## Revenue

### `GET /api/hospitality/billing/revenue`
**Query:** `propertyId`

Returns daily/monthly revenue, ADR, RevPAR, breakdowns by property, source, accommodation type, and market segment.

---

## Charge Categories

`accommodation`, `food_beverage`, `laundry`, `transport`, `spa`, `activities`, `telephone`, `miscellaneous`, `discount`, `service_charge`, `tax`

---

## Payment Methods

`cash`, `card`, `bank_transfer`, `digital_wallet`, `corporate_billing`, `credit_account`

---

## IIL Event Types (Finance Workspace)

| Event | Trigger |
|-------|---------|
| `ChargePosted` | Charge posted to folio |
| `PaymentReceived` | Payment processed |
| `FolioSettled` | Folio balance zeroed |
| `RefundIssued` | Refund processed |
| `DepositCollected` | Deposit held |
| `InvoiceGenerated` | Invoice created |
| `RevenueRecorded` | Revenue event stored |

All events include `financeWorkspaceTarget: true` in payload.

---

## Error Codes

| Code | Meaning |
|------|---------|
| `FOLIO_NOT_FOUND` | Invalid folio ID or org scope |
| `INVALID_FOLIO_STATUS` | Action not permitted for current folio status |
| `OUTSTANDING_BALANCE` | Settlement blocked by unpaid balance |
