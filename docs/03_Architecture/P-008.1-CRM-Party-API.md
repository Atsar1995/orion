# P-008.1 — CRM Party API Reference

**Mission:** P-008.1 — Universal Party & Organization Model  
**Base path:** `/api/crm`  

---

## Organisations

### `GET /api/crm/organisations`

Returns organisation directory with filter options.

### `POST /api/crm/organisations`

Creates an organisation party. Body: `CreateOrganisationInput`.

### `GET /api/crm/organisations/[id]`

Returns organisation detail with contacts and relationships.

### `PATCH /api/crm/organisations/[id]`

Updates organisation fields. Body: `ModifyPartyInput`.

### `GET /api/crm/organisations/[id]/relationships`

Lists relationships for an organisation.

### `POST /api/crm/organisations/[id]/relationships`

Links a relationship from the organisation. Body: `{ toPartyId, relationshipType, role?, notes? }`.

---

## Parties

### `GET /api/crm/parties`

Returns cross-party search results.

### `POST /api/crm/parties`

Creates a person party. Body: `CreatePersonInput`.

### `GET /api/crm/parties/search?query=&kind=`

Filtered party search.

### `GET /api/crm/parties/[id]`

Returns person or organisation detail.

### `PATCH /api/crm/parties/[id]`

Updates any party record.

### `GET /api/crm/parties/[id]/roles`

Lists role assignments for a party.

### `POST /api/crm/parties/[id]/roles`

Assigns a role. Body: `{ role, workspaceId?, notes? }`.

### `GET /api/crm/parties/[id]/identifiers`

Lists external system identifiers.

### `POST /api/crm/parties/[id]/identifiers`

Links an external identifier. Body: `{ system, externalId }`.

### `GET /api/crm/parties/[id]/timeline`

Returns executive memory timeline for a party.

### `GET /api/crm/parties/duplicates`

Returns duplicate person candidates with match scores.

### `POST /api/crm/parties/merge`

Merges duplicate identities. Body: `{ primaryPartyId, duplicatePartyId }`.

---

## Relationships

### `GET /api/crm/relationships/graph`

Returns relationship graph nodes and edges for ecosystem analysis.

---

## Authentication

All routes use `getDecisionServiceContext()` for tenant-scoped `ServiceContext`.
