# P-007.6 — Billing, Folio & Revenue Operations Platform Architecture

**Mission:** P-007.6 — Billing, Folio & Revenue Operations Platform  
**Epic:** P-007 Hospitality Workspace v1.0  
**Status:** Production-ready (in-memory persistence)  

---

## Purpose

The Billing, Folio & Revenue Operations Platform is the commercial accounting engine of the Hospitality Workspace. **Folio** is the canonical financial object — all charges, payments, deposits, refunds, and invoices attach to folios. Hospitality records operational financial events; enterprise accounting remains the responsibility of the Finance Workspace.

---

## Architecture

```
lib/hospitality/billing/
├── index.ts                 # HospitalityBillingFacade
├── billing-events.ts        # Financial event publisher (IIL → Finance)
types/hospitality-billing.ts
lib/hospitality/data/seed-billing.ts
lib/hospitality/repositories/BillingRepository.ts
lib/hospitality/mappers/billing-brief.ts
```

### Services

| Service | Responsibility |
|---------|----------------|
| `FolioService` | Folio lifecycle — create, detail, balance, settle |
| `ChargeService` | Charge posting with tax engine |
| `PaymentService` | Payments, deposits, refunds, adjustments |
| `InvoiceService` | Proforma, tax invoice, credit/debit notes |
| `RevenueService` | Revenue analytics and event recording |
| `BillingDashboardService` | Operational billing dashboard |
| `TaxEngine` | GST/tax calculation interface |
| `PricingService` | Rate lookup from reservation/accommodation |
| `BillingRulesEngine` | Folio status validation |

Public facade: `hospitalityBillingService`

---

## Domain Boundary (CTO Recommendation)

```
Hospitality (Operational)          Finance Workspace (Enterprise)
─────────────────────────          ─────────────────────────────
Folio → Charge → Payment    ──IIL──► Financial Events
Invoice generation                 General Ledger
Revenue analytics                  ERP integration
Guest billing                      Corporate accounting
```

Finance consumes financial events from Hospitality — it does not manage operational guest billing directly.

---

## Financial Event Flow

```
Charge Posted → Tax Record + Revenue Event → IIL (financeWorkspaceTarget: true)
Payment Received → Auto-settle if balance ≤ 0 → FolioSettled event
Invoice Generated → Invoice record + IIL event
```

---

## Success Definition

Operational billing remains decoupled from enterprise accounting while publishing standardized financial events for future ORION Finance Workspace integration.
