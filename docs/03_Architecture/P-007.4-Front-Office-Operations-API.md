# P-007.4 — Front Office Operations API

**Base path:** `/api/hospitality/front-office`  

---

## Dashboard

### `GET /api/hospitality/front-office`
**Query:** `propertyId`, `date`

Returns operational dashboard with occupancy, today's metrics, and queues (arrivals, in-house, departures, unassigned).

---

## Check-in

### `POST /api/hospitality/front-office/check-in`
**Body:** `CheckInInput` — `stayId`, optional `inventoryItemId`, `identityVerified`, `signatureCaptured`, `depositCollected`, `keyIssued`, `welcomeNotes`

**Errors:** `STAY_NOT_FOUND`, `ROOM_ASSIGNMENT_REQUIRED`, `ROOM_NOT_READY`, `INVALID_STAY_STATUS`

---

## Check-out

### `POST /api/hospitality/front-office/check-out`
**Body:** `CheckOutInput` — `stayId`, `expressCheckout`, `feedbackCollected`, `keyReturned`

**Errors:** `STAY_NOT_FOUND`, `OUTSTANDING_BALANCE`, `INVALID_STAY_STATUS`

---

## Room Assignment

### `POST /api/hospitality/front-office/assign-room`
**Body:** `{ "stayId": string, "inventoryItemId": string }`

### `GET /api/hospitality/front-office/assign-room?stayId=`
List available rooms for stay.

---

## Occupancy

### `GET /api/hospitality/front-office/occupancy`
**Query:** `propertyId`

Returns occupancy board with room buckets and in-house guest context.

---

## Stay Management

### `GET /api/hospitality/front-office/stays/[id]`
Stay detail.

### `PATCH /api/hospitality/front-office/stays/[id]`
**Body:** `StayMovementInput` — `type` (room_move | upgrade | downgrade | extension | shortening), `toInventoryItemId`, `newDeparture`, `reason`

---

## Error Codes

| Code | Meaning |
|------|---------|
| `STAY_NOT_FOUND` | Invalid stay ID or org scope |
| `INVALID_STAY_STATUS` | Action not permitted for current status |
| `ROOM_ASSIGNMENT_REQUIRED` | Check-in without assigned room |
| `ROOM_NOT_READY` | Inventory unit not clean/available |
| `OUTSTANDING_BALANCE` | Folio balance blocks checkout |
| `INVENTORY_NOT_FOUND` | Invalid inventory item |
