## Creating a New Entry

1. Copy `_TEMPLATE.md` to `DL-YYYY-NNN-short-title.md`
2. Complete all sections
3. Add row to this index and to [ORION Decision Log](../ORION_Decision_Log.md#decision-index)
4. Link related ADRs, ES, and RR documents

## ID Format

`DL-{year}-{sequence}` — e.g. `DL-2026-002`

Never reuse IDs. Never delete entries — mark **Superseded** and link to the replacement.
