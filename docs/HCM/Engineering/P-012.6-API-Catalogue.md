import { hcmFacade } from "@/lib/hcm";

| Service | Access |
|---------|--------|
| `AttendanceService` | `hcmFacade.attendance` |

## REST Endpoints (Time)

See [HCM API Catalogue — Time Routes](./HCM-API-Catalogue.md#time-routes-11) for the current route inventory and response envelopes.

### Attendance

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/hcm/attendance` | Search attendance (paginated) |
| POST | `/api/hcm/attendance` | Record attendance |
| POST | `/api/hcm/attendance/correct` | Correct attendance |

### Leave

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/hcm/leave` | Search leave requests |
| POST | `/api/hcm/leave` | Create leave request |
| POST | `/api/hcm/leave/actions` | Approve / reject / cancel |
| GET | `/api/hcm/leave/balance` | Balance and policies |

### Roster

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/hcm/roster` | List rosters |
| POST | `/api/hcm/roster` | Create roster |
| POST | `/api/hcm/roster/publish` | Publish roster |

### Calendars

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/hcm/calendars` | Holiday and work calendars |

## Response Envelope (v1.0)

```json
{ "success": true, "data": { "items": [], "pagination": { "page": 1, "pageSize": 50, "total": 0 } } }
```
