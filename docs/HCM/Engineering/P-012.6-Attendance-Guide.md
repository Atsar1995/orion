# P-012.6 Attendance Guide

**Mission:** P-012.6 – Attendance, Leave & Rostering  
**Module:** HCM Time & Attendance

## Overview

The attendance module records employee presence through multiple capture channels and supports corrections with workflow approval.

## Capture Channels

| Source | Description |
|--------|-------------|
| `manual` | HR or manager entry |
| `biometric` | Biometric device integration |
| `mobile` | Mobile check-in |
| `remote` | Remote work attendance |
| `correction` | Approved attendance correction |

## Attendance Statuses

- `present`, `absent`, `late`, `half_day`, `remote`, `on_leave`, `holiday`, `corrected`

## Service API

Use `AttendanceService` via `hcmFacade.attendance` or `attendanceService`:

```typescript
attendanceService.record({
  employeeId: "emp-hcm-001",
  attendanceDate: "2026-07-31",
  status: "present",
  source: "manual",
  checkInAt: "2026-07-31T09:00:00.000Z",
  checkOutAt: "2026-07-31T18:00:00.000Z",
}, context);
```

## REST API

- `GET /api/hcm/attendance` — search attendance records
- `POST /api/hcm/attendance` — record attendance
- `POST /api/hcm/attendance/correct` — submit correction (triggers workflow)

## Business Rules

- One attendance record per employee per calendar date
- Half-day attendance supported via `isHalfDay: true`
- Missing checkout generates an `AttendanceException`
- Corrections publish `AttendanceCorrected` with workflow template `hcm.attendance.correction`

## Events

- `AttendanceRecorded`
- `AttendanceCorrected`
