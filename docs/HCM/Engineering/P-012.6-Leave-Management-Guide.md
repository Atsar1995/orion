# P-012.6 Leave Management Guide

**Mission:** P-012.6 – Attendance, Leave & Rostering  
**Module:** HCM Leave

## Overview

Leave management supports request submission, approval workflows, balance tracking, accrual, carry-forward, and partial-day leave.

## Leave Types

`annual`, `sick`, `unpaid`, `compensatory`, `maternity`, `paternity`, `study`, `other`

## Request Lifecycle

```
draft → pending → approved | rejected
                 ↘ cancelled
```

Sick leave with `requiresApproval: false` auto-approves on submission.

## Service API

```typescript
const request = leaveService.createRequest({
  employeeId: "emp-hcm-001",
  leaveType: "annual",
  startDate: "2026-09-01",
  endDate: "2026-09-03",
  duration: { value: 3, unit: "days" },
  partialDay: false,
}, context);

leaveService.approve(request.id, context, "emp-hcm-mgr");
```

## Balance & Accrual

```typescript
leaveService.getBalance("emp-hcm-001", "annual", context);
leaveService.accrueBalance("emp-hcm-001", "annual", 1, context);
leaveService.carryForward("emp-hcm-001", "annual", context);
```

## REST API

- `GET /api/hcm/leave` — search leave requests
- `POST /api/hcm/leave` — create leave request
- `POST /api/hcm/leave/actions` — approve, reject, or cancel
- `GET /api/hcm/leave/balance` — balance and policies

## Workflow Integration

Pending requests publish `LeaveRequested` with workflow template `hcm.leave.approval`.

## Events

- `LeaveRequested`, `LeaveApproved`, `LeaveRejected`, `LeaveCancelled`
